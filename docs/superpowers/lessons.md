# Lessons

One line each, written as a rule for how later work is split or briefed. The coordinator reads this before writing a brief. A lesson that keeps coming back moves into CLAUDE.md in the daily rules batch and leaves this file.

- A refusal that can happen on a press is checked before any "are you sure?" question on that press, so a person is never asked to confirm something that is then refused (harsh look HL4).
- A refusal belongs right above the thing it is about, and its words name that thing; a part's heading is not enough when a part holds two questions (HL1).
- Two controls that do different jobs sit with their own explaining line, never with another control between them (HL2).
- A refusal inside a block of someone else's words wears the look's "needs fixing" edge, so it is never read as part of those words (HL3).
- Scrolling a page to a place waits for the page's entrance animations to finish, because a moving line is measured where it is, not where it will rest (HL3).
- A bar with more links than its narrowest window can hold shrinks its links at that size, so it never wraps to a second line (HL5).
- A dot between facts is written with the words after it, so a line never starts or ends with one (HL6).
- A height that must fit the window counts every bar and gap above the thing, not only the thing's own margin (HL7).
- A button under a picture has the same step above it as the picture has above itself, so it is not read as the picture's caption (HL8).
- Two pages of one area share one rule for their bar, so it starts at the same edge as the page under it (HL9).
- A page that is drawn outside its area's layout gets what that layout would have given, such as the wordmark, from the page that hides it (HL10).
- A link that staff use every day is never the line right above "Delete my account"; the way to delete keeps a clear step (HL11).
