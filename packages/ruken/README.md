# ruken

Ruken from your computer. Sign in once, then send your games and videos from a terminal.

```
npx ruken sign-in
npx ruken games
npx ruken video my-game upright my-video.mp4
```

Type `npx ruken` to see the commands. You press **Yes** on ruken.io once; after that this computer can act for you,
and you can remove it any time on ruken.io/me/computers.
